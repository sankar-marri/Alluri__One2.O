# Alluri ONE

**Alluri ONE** is a responsive, real-world-style digital governance roadmap platform for Alluri Sitarama Raju District.

## Features

- 36-week, nine-phase project roadmap
- Responsive desktop and mobile interface
- Interactive roadmap cards
- Project overview, technology stack and impact metrics
- Animated success counters
- Accessible introduction modal

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

No build step or third-party JavaScript package is required.
